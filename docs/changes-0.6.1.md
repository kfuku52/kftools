# Changes in 0.6.1

This release corrects documentation and source-distribution contents. Numerical
algorithms, defaults, signatures, and runtime dependencies are unchanged from
[0.6.0](changes-0.6.0.md).

- Explain expression back-transformation, default median regression, missing
  values, partially supported F1X4 operations, and inverse branch weighting.
- Correct tree naming and mutation descriptions, distinguish branch IDs from
  dataframe row order, and describe taxonomy database initialization.
- Document OU schemas and expression scales, FASTA restrictions, ModelFinder
  checkpoint input, and the partial results returned by log readers.
- Add executable sequence, statistics, plotting, and OU examples; clarify
  dependency-snapshot upgrades, clean environments, and wheel selection.
- Include guides, images, development helpers, constraints, benchmarks, and
  tests in source archives, and add a documentation URL to package metadata.
